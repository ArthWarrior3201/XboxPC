# XboxPC website

Feedback is omitted as requested. No feedback branch or endpoint is needed.

Enable GitHub Pages with GitHub Actions in Settings > Pages. The included workflow publishes index.html and assets.

Create a GitHub Release and attach **XboxPC-v1.zip**. The Download button uses the latest published release asset with that filename. No release is created automatically.

The ZIP contains the original v1 source package, renamed as requested. Commercial Xbox translation remains unsupported.
